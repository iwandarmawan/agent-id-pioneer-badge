# Agent ID Pioneer Badge — mint site

Static single-page site for the free commemorative badge. No backend, no
private keys, no QR-code login, no auto-signing, no bundled transfers.

## Files

- `index.html` — the page (connect wallet, eligibility check, Mint button).
- `app.js` — wallet + contract logic (ethers v6).
- `config.js` — addresses and chain settings. **`BADGE_CONTRACT_ADDRESS`
  is empty until the contract is deployed — fill it in after deploy.**
- `vendor/ethers.min.js` — ethers v6.13.4, vendored locally (sha256
  `562de2cfc9021c75453b04c75587d20311fb585a6fb4acce5d872d21036170c2`).
  Vendored instead of a CDN because the CDN failed to load in the headless
  render test; a static site should not depend on a third party at runtime.
- `images/badge.svg` — original badge artwork (no third-party branding).
- `metadata/` — 1,000 token metadata files (`1.json` … `1000.json`),
  generated by `../scripts/gen-metadata.js` for the GitHub Pages URL
  `https://iwandarmawan.github.io/agent-id-pioneer-badge/`.

## Publish on GitHub Pages

Repo: https://github.com/iwandarmawan/agent-id-pioneer-badge

1. Copy the whole `site/` directory into the repo root (so `index.html` is
   at the repo root).
2. Push to GitHub, then enable Pages: repo Settings → Pages → Source:
   “Deploy from a branch”, branch `main`, folder `/ (root)`.
3. The site is live at `https://iwandarmawan.github.io/agent-id-pioneer-badge/`.
4. After the contract is deployed, edit `config.js` in the repo and set
   `BADGE_CONTRACT_ADDRESS` to the deployed address, then push again.
5. After the metadata files are in the repo, call `setBaseURI` on the
   contract with `https://iwandarmawan.github.io/agent-id-pioneer-badge/metadata/`
   (see `../DEPLOY-NOTES.md`). Until then `tokenURI` returns `""`, which is
   by design — badges still mint and are owned on-chain.

## What the page does

- Connects with `window.ethereum` (user's own wallet extension).
- Reads the visitor's Agent ID balance on-chain and shows eligibility.
- The Mint button sends one transaction, `mint()` with no value attached.
  The user reviews and confirms it in their own wallet; nothing is
  auto-signed and no other transfer is bundled.
- If the visitor is on the wrong network, the page offers the standard
  wallet network switch to BNB Smart Chain (chain 56).
